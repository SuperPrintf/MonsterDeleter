小怪兽删除器已安装完成。

使用方法
1. 在资源管理器中右键单击要删除的文件或文件夹。
2. 选择“召唤小怪兽删除”。
3. 按屏幕提示选择目标；按 Esc 可随时取消。

卸载软件与设置
当目标是软件快捷方式时，小怪兽会使用内置的 BCUninstaller 识别组件定位唯一的软件，并提供卸载或仅删除快捷方式的选择。默认使用软件自身的官方卸载界面，不执行强制删除或残留清理。
安装页可选“首次建立软件卸载索引”（默认不勾选）。勾选后会在安装完成阶段枚举 Windows 已安装软件的可卸载记录（注册表与 MSI），供后续快捷方式识别使用；不会扫描磁盘中的孤立文件，也不会执行容易受 Windows Update 影响的系统功能扫描。
可从开始菜单打开“Monster Deleter 设置”，按需启用或关闭“启用卸载功能”，以及“卸载功能静默执行”。关闭卸载功能后，软件快捷方式也会直接执行原有的小怪兽删除逻辑。该设置仅作用于当前 Windows 用户，保存在明文文件：%LOCALAPPDATA%\MonsterDeleter\config.toml。
卸载功能静默执行会尽量跳过软件自身的卸载界面，但仍可能显示 UAC 或厂商窗口；默认不会扫描或清理残留文件、文件夹及注册表项。
内置识别组件基于 BCUninstaller v6.1，采用 Apache-2.0 许可证；许可证与声明位于安装目录的 assets\tools\bcu-bridge 文件夹。

卸载方法
请打开“控制面板 → 程序和功能”，选择“Monster Deleter”，然后单击“卸载”。
卸载程序会同时移除资源管理器右键菜单中的“小怪兽删除”入口。
